# Images (all of them are here)

- `trash-cat.png`: the cat in the bin (transparent), shown on the Trash screen. Loaded with `require('../../assets/images/trash-cat.png')`.
- `moodImages.js`: the five mood cats stored as text (base64), used by `components/MoodFace.js` and `components/EntryPreview.js`.
- `teaserImages.js`: the cat stickers in the Plus preview cards stored as text (base64), used by `components/MemoriesTeaser.js`.

Add any new picture to this folder.
